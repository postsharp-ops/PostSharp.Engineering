# Tray Icons

This directory should contain the following icon files:

- `tray-normal.ico` - Normal state icon (green checkmark or similar)
- `tray-pending.ico` - Attention required icon (yellow/orange warning or similar)

## Icon Requirements

- Format: ICO
- Recommended sizes: 16x16, 32x32, 48x48, 256x256 (multi-resolution ICO)
- Color:
  - Normal: Green or blue to indicate "ready" state
  - Pending: Yellow/orange or red to indicate "attention needed" state

## Temporary Solution

Until proper icons are created, the application will fall back to default icons.
You can use any icon editor or online tool to create these icons.

Suggested tools:
- GIMP with ICO plugin
- IcoFX
- Online converters (e.g., convertio.co)
